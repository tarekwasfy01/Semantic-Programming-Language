GitHub Pages hosting

This website is designed to be hosted with GitHub Pages. GitHub may process technical request information needed to deliver the site, such as IP addresses, request timestamps and browser information, according to GitHub's own privacy documentation.

Module Registry

The public registry file stores only the module name and the external release URL supplied for the module. The website does not intentionally store GitHub passwords, module archives, README files, license files or module icons.

Publishing a module

Publishing uses GitHub as the authentication and submission layer. When you continue with GitHub, you leave this website and use GitHub's own service. The resulting public submission may be processed by a GitHub Actions workflow in order to validate the external ZIP archive and update the registry.

External module content

When a module page is opened, the visitor's browser may fetch a module ZIP, README, license, icon or repository metadata directly from the external URL. This is necessary to display module information without copying it to this website. The external provider can receive ordinary network information, including the visitor's IP address and browser request metadata.

Third-party badges

The homepage can load a Go Reference badge from pkg.go.dev and a Microsoft Store badge from Microsoft. Loading these resources connects the visitor's browser to those providers. Their own privacy terms apply.

Cookies and analytics

The supplied website does not add analytics, advertising trackers or its own cookies. If you later add analytics or other third-party services, update this policy before enabling them.

Git history

Although the current registry contains only names and URLs, changes committed to Git can remain visible in repository history. Removing a current registry entry does not automatically erase historical commits.

Your rights

Applicable data-protection rights depend on the circumstances and legal basis of processing. This template is not legal advice; review it for your final deployment, services and domain setup.
