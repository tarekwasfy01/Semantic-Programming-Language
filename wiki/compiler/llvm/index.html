Why LLVM

LLVM is useful as a backend because it separates the language front end from architecture-specific native code generation.

  • Native compilation
  • Multiple target architectures
  • Optimization infrastructure
  • A mature compiler backend

The LLVM path complements the Code Transpiler CLI, which focuses on source-to-source compilation.
