Self-Hosting

A long-term goal of Semantic is a self-hosted compiler: Semantic compiling Semantic.

Self-hosting means that more and more of the compiler can eventually be implemented in the language it compiles.

Why It Matters

  • Demonstrates that Semantic can implement substantial compiler infrastructure.
  • Reduces dependence on external implementation languages over time.
  • Creates a demanding real-world test for the language and module system.
  • Provides a clear bootstrap path for the project.
Project direction: self-hosting is a goal and development path, not a claim that the compiler is already fully self-hosted.
