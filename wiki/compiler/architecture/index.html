Compiler Architecture

The Semantic toolchain is intended to support different outputs for different environments.

Shared Front-End Work

A compiler path typically begins by reading Semantic source, parsing it, validating language rules, and producing a representation that can be transformed by a backend.

Semantic Source
      ↓
    Parser
      ↓
Semantic Analysis
      ↓
Compiler Representation
      ↓
 Backend / Transpiler

Backends and Paths

  • Mini MSPLC supports compact compiler development and bootstrapping.
  • LLVM provides a route to LLVM IR and native machine code.
  • Code Transpiler CLI provides source-to-source compilation into existing ecosystems.

This multi-path design allows Semantic to participate in native compilation, source transformation, and the compiler bootstrap process at the same time.
