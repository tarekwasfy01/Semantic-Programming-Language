## Compiler change

Four specialized binary-operation lowerers now validate their Semantic relation contracts before emitting machine code:

- `compile_signed_division_expr`
- `compile_unsigned_division_expr`
- `compile_unsigned_shift_expr`
- `compile_unsigned_compare_expr`

Each requires exactly one left and one right edge. A mismatch sets the existing compiler error state and returns before code emission. The existing operator-specific lowering and x64 emitters remain in place.
