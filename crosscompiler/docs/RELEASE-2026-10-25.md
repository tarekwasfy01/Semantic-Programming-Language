## Native changes

- `node_get` returns a sentinel for negative IDs and IDs above the parsed maximum before reading node memory.
- `node_set` rejects negative IDs and sets the context error before writing node memory.
- `parse_node_line` checks the node allocation capacity before the first write. `parse_source` propagates its error to the compile path.
- The native SMOD merge arena is 32 MiB. The previous 16-MiB arena crashed on a sparse graph at node ID 299,593; the new candidate compiled and executed fixtures at IDs 299,593, 300,000, 500,000, and 599,185 with exit code 42. ID 599,186 was rejected without an EXE.

These checks cover the exercised inputs. They do not prove complete UAST coverage, all transpiler routes, or absence of intermittent failures under other workloads.
