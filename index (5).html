Modules

Modules organize Semantic applications into clear, reusable building blocks.

For larger programs, modules provide boundaries for related functionality and help developers, AI systems, compilers, and tools reason about a project in smaller units.

Application
├── Core Module
├── AI Module
├── Data Module
├── Automation Module
└── Integration Module

Why Modules Matter

  • Keep large applications structured.
  • Encourage reusable functionality.
  • Provide predictable boundaries for automated analysis.
  • Make compiler components easier to isolate and evolve.
  • Support the long-term self-hosting strategy.

Compiler-related functionality can gradually move into dedicated Semantic modules as the language and toolchain mature.
