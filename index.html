The language

Meaning first. Syntax second.

Semantic is built around a UAST-derived representation so programs can be expressed by their intent and relations rather than by the accidental surface form of a single language. It is designed as a universal programming language for AI, tooling and cross-language software understanding.

01 / MEANING

Semantic-rich by design

Meaning, relationships and program structure stay central. Syntax is an expression layer, not the identity of the program.

02 / UAST

Derived from a UAST

A universal abstract syntax foundation enables Semantic to reason across different source languages while preserving a common structural model.

03 / UNIVERSAL

Built beyond language

Use one semantic layer for AI and tooling instead of forcing the machine to learn every language as an isolated world.

Made for AI

Let AI speak in meaning, not syntax.

Semantic is specifically made for AI as a universal programming language. The goal is not to make AI imitate every programming language independently, but to give it a common semantic representation from which language-specific forms can be understood, generated and transformed.

Universal modules

Import modules from all languages.

Semantic modules are designed to bridge ecosystems. Import modules originating from other languages and make their capabilities available through a shared semantic model, without pretending every ecosystem uses the same syntax.

One module system, many source languages.

A Semantic module can describe its contents in a .smod manifest and be distributed as a portable ZIP archive. The module store can then import it through the CLI, Go API or manual installation.
